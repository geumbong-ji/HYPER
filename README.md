# HYPER

**Hybrid Framework Combining Iterative Pre-Trained Supervised Image Priors with Neural Representation for Extremely Sparse-view CT Reconstruction**

HYPER is a hybrid framework for CT reconstruction from extremely sparse projection views. It combines iterative supervised image restoration and streak artifact reduction (ResNet–SAR) with implicit neural representation (INR)-based refinement to preserve anatomical details while improving consistency with measured projection data.
